# Changelog

## [1.1.0] - 2026-11-07
### Added
- Sigmoid confidence calibration in prediction engine
- Configurable execution timeout for commands
- `clear` and `history` built-in terminal commands
- Command history bounded to 500 entries

### Fixed
- Unbounded memory growth in long-running sessions

## [1.0.0] - 2026-10-18
### Initial release
- Neural prediction engine with transformer backend
- Interactive terminal interface
- Command processor with subprocess integration
